Proyecto 3 – Power BI: Reporte de Ventas

Objetivo

Construir un reporte de ventas en Power BI a partir de datos reales de una empresa, realizando limpieza, modelamiento, análisis y visualización de la información.

Caso analizado

Caso 09 – Polar.

Trabajo realizado

* Limpieza y transformación de las tablas Ventas, Productos y Sucursales mediante Power Query.
* Corrección de tipos de datos, duplicados, textos inconsistentes y otros problemas presentes en la base.
* Creación de las variables Venta y Costo.
* Construcción del modelo de datos y relaciones entre las tablas.
* Creación de medidas DAX, incluyendo ventas totales, número de ventas, ticket promedio y margen porcentual.
* Diseño de tarjetas KPI y visualizaciones de ventas.
* Análisis de ventas a través del tiempo, categorías y sucursales.
* Incorporación de segmentadores para explorar la información.
* Respuesta a preguntas de negocio utilizando cifras obtenidas del modelo.

Herramienta

Microsoft Power BI.

Archivos

* Reporte de Power BI en formato .pbix.
* Base de datos utilizada para el análisis.
* Informe con contexto, hallazgos y respuestas de negocio.
