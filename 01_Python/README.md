Proyecto 1 – Python: Visualización de una Serie de Tiempo

Objetivo

Analizar y visualizar una serie de tiempo económica utilizando Python en Google Colab.

Serie analizada

Serie de tiempo relacionada con tasas de desocupación.

Trabajo realizado

* Importación de las bibliotecas necesarias.
* Carga y revisión de la base de datos.
* Exploración de las primeras observaciones, columnas y tipos de datos.
* Revisión de valores faltantes.
* Conversión y ordenamiento de la variable fecha.
* Identificación de la variable principal de la serie.
* Elaboración de un gráfico de evolución temporal.
* Interpretación de la tendencia, fluctuaciones y períodos con valores especialmente altos o bajos.

Herramienta

Python – Google Colab

Archivos

* Notebook de análisis en formato .ipynb.
* Base de datos utilizada para la serie de tiempo.
